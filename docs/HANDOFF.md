## כללי עבודה שסוכמו
- **פריסה:** רק באישור מפורש. לפני כל פריסה מגבים את D1:
  ```bash
  npx wrangler d1 export renovation-db --remote --output <file>
  ```
- **בסביבת הענן:**
  - פורסים עם `npm run build:deploy` ואחר כך `npx wrangler deploy --config wrangler.deploy.json`.
  - הקבצים הסטטיים נכללים בתוך ה־Worker, כי ה־proxy של הסביבה שובר את העלאת ה־Static Assets.
  - `CLOUDFLARE_API_TOKEN=proxy-injected`: את המפתח עצמו ה־proxy מזריק.
- **מיגרציות:** מריצים לפני הפריסה, עם `npx wrangler d1 migrations apply renovation-db --remote`.
- **זהות המשתמש:** רק מ־Access. אסור לבקש מהמשתמש להדביק סודות בצ'אט.
- **תיעוד:** הפירוט המלא נמצא ב־`README.md` וב־`docs/SPEC.md`.
